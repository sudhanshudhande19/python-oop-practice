# 10. Interview Questions — Short & Easy Answers

### Q1. What is the Walrus Operator in Python?

**Answer:** It is `:=`, used to assign and use a value in one expression.

### Q2. In which Python version was it introduced?

**Answer:** Python 3.8.

### Q3. What is another name for the Walrus Operator?

**Answer:** Assignment Expression Operator.

### Q4. What is the difference between `=` and `:=`?

**Answer:** `=` assigns a value; `:=` assigns a value and works inside an expression.

### Q5. What is an assignment expression?

**Answer:** An expression that assigns a value to a variable and also evaluates to that value.

### Q6. Can the Walrus Operator be used inside an `if` condition?

**Answer:** Yes. Example: `if (n := 10) > 5:`

### Q7. How can it be used inside a `while` loop?

**Answer:** Assign input in the condition and repeat until the stop condition is met.

### Q8. Can it be used with list comprehensions?

**Answer:** Yes. It can save a calculated value while filtering items.

### Q9. What are the advantages of the Walrus Operator?

**Answer:** It avoids repeated calculations and can make code shorter.

### Q10. When should you avoid using the Walrus Operator?

**Answer:** Avoid it when it makes code confusing or harder to read.

### Q11. Does the Walrus Operator return the assigned value?

**Answer:** Yes. The assignment expression evaluates to the assigned value.

### Q12. Why can parentheses be required when using `:=`?

**Answer:** Some Python expression contexts require parentheses to make the assignment expression clear and valid.
